SDC320 Week 1 - Rolodex Contacts Application
Cora Germany | November 15, 2026

Open this folder in VS Code (the folder containing RolodexContacts.csproj).
In the integrated terminal, run:
    dotnet run

The Week 1 application displays a welcome banner and sample contacts.
Interactive add/remove/update/search are part of the future UX plan, not this week's implementation.
All contact names, emails, addresses, and telephone numbers are fictional examples.
